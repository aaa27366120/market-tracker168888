# 上市、上櫃官方個股行情資料

本資料管線與既有市場儀表板資料分開，避免擴大 `docs/data.json`，也避免個股行情更新失敗影響既有指數與期貨更新。

## 官方來源

| 市場 | 公司名單 | 每日行情 |
|---|---|---|
| 上市 | [TWSE 上市公司基本資料](https://openapi.twse.com.tw/v1/opendata/t187ap03_L) | [TWSE STOCK_DAY_ALL](https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL) |
| 上櫃 | [TPEx 上櫃公司基本資料](https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap03_O) | [TPEx 每日收盤行情](https://www.tpex.org.tw/openapi/v1/tpex_mainboard_daily_close_quotes) |

公司名單用來限制個股範圍，避免把行情端點中的 ETF、權證或其他非公司證券直接當成普通公司股票。上市、上櫃各自保留市場欄位。

## 輸出檔

- `docs/stocks.json`：上市與上櫃各自的最新成功快照。
- `stock_data.py`：獨立收集、正規化、驗證及原子寫入。
- `.github/workflows/update-stocks.yml`：台灣時間週一至週五 18:37 排程，可手動執行。

每筆行情統一欄位：市場、股票代號、名稱、交易日期、開高低收、漲跌、成交股數、成交金額、成交筆數、資料來源。

## 資料品質規則

1. 兩個市場分開抓取、分開驗證；一個市場失敗不覆蓋另一市場的最後成功快照。
2. HTTP 成功不等於資料有效；必須是 JSON 陣列、公司名單有效、行情日期一致、有效股票筆數達最低門檻、代號不重複，且 OHLC 關係合理。
3. 日期使用民國年時先轉成 ISO 西元日期；數字字串先去逗號再轉型。
4. 若來源回傳日期早於已保存日期，拒絕覆蓋。
5. 來源失敗時保留舊行情，並更新該市場的 `status=failed`、`checked_at`、`error` 及 `last_success_date`。
6. 這兩個每日行情 API 是最新交易日快照，不提供完整歷史區間；本專案從開始收集後逐日累積。不得把本系統開始收集前的空白歷史補成推測值。
7. 這是每日收盤行情，不是盤中即時報價；網站呈現時必須明確標示交易日期。

## 目前範圍與後續工作

本階段先建立官方資料收集與保存基礎，不直接改動首頁版面，也不接入即時報價。下一步再驗證 GitHub Actions 實際連線狀態、資料筆數及欄位完整度，通過後才規劃個股搜尋與呈現。官方交易日曆可在後續接入，供資料新鮮度檢查與休市判斷使用。
