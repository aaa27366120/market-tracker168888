# Market Tracker（市場觀察）

這是一個以 GitHub Pages 發布的靜態市場觀察頁面。資料由 GitHub Actions 執行 `fetch_data.py` 更新，寫入 `docs/data.json`。

## 專案檔案

- `fetch_data.py`：抓取公開行情、計算近 60 日支撐、均線、量比、一年高點回落，以及日／週／月趨勢、RSI(14)、MACD、20 日動能與市場風險評分。
- `docs/data.json`：網站讀取的資料檔；每個標的保留自己的行情日期，並內含 `fut_hist`（台指期自行累積的歷史）。
- `docs/index.html`：市場觀察頁面，含證交所「投資人違約概況」官方連結及第三階段市場分析區。
- `.github/workflows/update.yml`：依台股、美股交易時段排程更新（詳見下方「更新排程與資料狀態」），也可手動執行。

## 第三階段：市場分析

- 各標的以同一份公開日線資料推導日、週、月趨勢；日線使用 MA20／MA60，週線使用 12／26 週均線，月線使用 3／6 月均線。
- 技術指標包含 RSI(14)、MACD（12、26、9）、MA20／MA60／MA120 與 20 日動能。歷史資料不足時回傳「資料不足」，不填入推測數值。
- 市場風險分數以台灣加權、標普 500、那斯達克及費城半導體四個指數等權計算。收盤低於 MA60 +25、MA20 低於 MA60 +20、RSI14 < 40 +20、MACD 柱狀體 < 0 +20、20 日動能 < 0 +15；至少兩個有效指數才計算。分數是技術風險觀察，不是預測或買賣訊號。
- 每個分析標的顯示行情日期與實際採用來源（Yahoo Finance 或 Stooq）；使用舊行情時不納入市場風險分數。
- 「信用風險監控」卡片直接連結證交所臺股儀表板「投資人違約概況」，本站不重複抓取該頁數字。

## 更新排程與資料狀態

排程在 `.github/workflows/update.yml`（UTC；台灣 = UTC+8，GitHub 可能延遲數十分鐘）：

| 時段 | 台灣時間 | 抓什麼 |
|---|---|---|
| 台股盤中 | 週一到週五 09:07–13:37，每 30 分鐘 | 只抓正在交易的市場（加權指數、黃金、石油、匯率，約 4 個請求；美股指數沿用上次資料）；最後一次 13:37 補抓收盤價 |
| 台指期日盤收盤後 | 週一到週五 14:07 | 玩股網收盤報價，並嘗試抓期交所官方資料 |
| 台股收盤後 | 週一到週五 16:07、18:07 | Yahoo + 證交所（外資、成交金額）+ 期交所（台指期）；當天已有資料就不重抓 |
| 美股交易時段 | 約 22:07–06:07，每 2 小時 | 只抓正在交易的市場；最後一次（06:07）補抓美股收盤價，美國夏令冬令都涵蓋 |

- 證交所與期交所資料只在台股收盤後抓（開盤前 05:00–09:00 的那次只補抓台指期夜盤最新價）；手動執行（Run workflow）會全部重抓。
- 沒有內建休市日曆，休市日照常執行；卡片標籤會顯示「休市或無新資料」。
- 「只抓開盤中市場」的做法：每筆行情會記錄是不是盤中抓的（`captured_open`），市場收盤後補抓一次最終價，之後到下次開盤前都沿用；手動執行（Run workflow）會全部重抓。
- 排程刻意避開整點（GitHub 在整點最容易延遲或丟失排程）；GitHub 排程為盡力而為，實際執行時間可能延遲數分鐘到數十分鐘。
- 卡片狀態標籤：盤中、已收盤、交易中、休市、上一交易日資料、休市或無新資料。盤中不顯示量比。
- 卡片下方的 Yahoo 與 TradingView 連結定義在 `fetch_data.py` 的 `LINKS`，代碼未逐一實測，請點過確認。

## 台指期的網頁報價（可關閉）

- 台指期（近月）：台股交易時段每小時（09:07、10:07、11:07、12:07、13:07，另加 14:07 抓收盤）從玩股網 `WTX&` 抓報價；台指期（全）：16:07、18:07、22:07、00:07、02:07、04:07、06:07 從 Yahoo 奇摩 `WTX&` 抓報價。
- 網頁報價來自第三方網頁，是盤中參考價，可能延遲，也不是官方資料。期交所官方資料只在收盤後公布；官方資料出來後，一律以官方為準，卡片上的來源列會標示「網頁報價」或「期交所官方」。
- 抓取失敗時，卡片自動改顯示期交所官方資料，並說明原因與日期；被網站拒絕（HTTP 403／429 或驗證畫面）時，當天不再重試。網頁報價超過 36 小時就不再使用。
- 一鍵關閉：把 `fetch_data.py` 最前面的 `ENABLE_WEB_QUOTES = True` 改成 `False`，或在工作流程設定環境變數 `WEB_QUOTES=0`，就完全不抓網頁，只用官方資料。
- 每次抓取的結果（狀態碼、有沒有找到價格、報價附近的文字片段）會寫進 `docs/fut_probe.json`，抓不到時用來找原因；最多保留最近 40 筆。手動執行（Run workflow）會立刻抓兩個網站。
- 台指期（全）會顯示夜盤（或盤後）價格對最近一個日盤收盤的差（點數與百分比）；收盤後，網頁報價會和期交所官方收盤核對（差距超過 0.05% 標示異常）。
- 風險提醒：兩個網站是否允許自動擷取、報價轉載是否需要授權，本專案沒有確認；網站改版或擋掉 GitHub 的伺服器時，抓取會失效（卡片會退回官方資料）。連結：近月→玩股網，全→Yahoo 與 TradingView K 線（`TAIFEX:TXF1!` 通用網址）。

## 資料核對與盤中標示

- **收盤核對**：加權指數收盤後，程式用證交所「每日市場成交資訊」（`FMTQIK`）公布的指數收盤，和 Yahoo 的收盤價比對；差距超過 0.05% 會在卡片與市場分析標示異常。盤中或日期對不上時顯示「待收盤後核對」，欄位抓不到時顯示「無法核對」。
- **含盤中資料**：每筆行情記錄是否為盤中抓取（`captured_open`）。市場分析中的項目若最新一根日線尚未收盤，會標示「含盤中」，風險卡也會提醒分數可能在收盤後變動。
- **成交金額口徑**：加權指數的成交金額取自證交所「每日市場成交資訊」，可能與新聞常引用的集中市場成交金額不同；量比使用同一來源的連續資料。
- **市場分析的價格**：每個項目顯示收盤價、漲跌幅、距 MA20 與距 MA60，取自同一份行情資料。

## 台指期與成交量

- 台指期（近月）：期交所開放資料中近月合約的一般交易時段。台指期（全）：盤後＋一般盤合併，收盤取一般盤收盤。
- 期交所開放資料只提供最新一日，歷史由程式每天累積；累積滿 5 個交易日才計算支撐與量比，近月換月會造成價格跳動。
- 加權指數的量比改用證交所成交金額（`FMTQIK`）；美股指數與匯率沒有可比成交量，不顯示。
- 期交所與證交所的欄位名稱曾無法在開發環境實測；若抓取失敗，頁面會標示舊資料，Actions 日誌會印出實際欄位。

## 第一階段資料品質規則

1. 一年高點回落 15%／25% 僅為回落幅度觀察，不是買進、加碼或進場訊號。
2. 指數與匯率不顯示不具可比性的成交量比；成交量缺漏或為 0 時，量比顯示為無資料，不當成 0 倍量。
3. 外資資料記錄抓取狀態、來源資料日期與檢查時間。抓取失敗時沿用既有歷史資料，但頁面會明確標示舊資料。
4. 單一行情來源失敗時，嘗試備援來源；若仍失敗，保留上一筆有效行情並標示為舊資料，不把更新失敗偽裝成新行情。
5. 更新程式以暫存檔寫入 JSON，避免寫檔中斷造成資料檔損毀。
6. 若所有行情標的都更新失敗，GitHub Actions 驗證步驟會失敗，不會把失敗快照提交到正式網站。

## 本機檢查

需要 Python 3.10 以上，以及 `pandas`、`requests`、`yfinance`。可執行：

```bash
pip install pandas requests yfinance
python -m py_compile fetch_data.py
python fetch_data.py
```

執行 `fetch_data.py` 需要網路連線，且公開資料來源可能延遲、限流或暫時不可用。請檢查 `docs/data.json` 中的 `update_status`、各標的 `date`／`stale`，以及 `foreign_meta`，不要只看程式執行時間。

## 使用限制

本頁僅整理公開市場資訊，不構成投資建議。行情可能延遲或有誤，應以交易所及資料提供者公告為準。
